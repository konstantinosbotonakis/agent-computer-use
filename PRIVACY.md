# Privacy policy

Agent Computer Use is a Chrome extension plus a small program that runs on your own computer. This policy covers both.

## What the extension handles

The extension works only when coding agents on your computer ask it to. It handles:

- **Tab details:** the title, URL and tab group of your open tabs, when an agent asks for the tab list.
- **Website content:** the text, page structure, screenshots, console messages and network request details of tabs that an agent opened or that you asked it to use.
- **Input you ask an agent to make:** text the agent types and the clicks and key presses it sends to those tabs.

## Where that data goes

The extension sends this data only to the Agent Computer Use program on the same computer, through Chrome native messaging. That program passes it to the coding agents you connected. It does not leave your computer through the extension.

What a coding agent does with the data after that is governed by that agent and its provider, not by Agent Computer Use. Many agents send what they read to a cloud AI model.

## What is not collected

The developer collects nothing. The extension and the local program contain no analytics, telemetry, advertising or remote servers, and they store no data beyond what Chrome keeps while a tab is open.

## Limited use

Data from the extension is used only to let your own agents work in your browser. It is not sold, not used for advertising, not used to determine creditworthiness, and not transferred to anyone else.
