Connect any MCP agent in three steps.

Works with Codex, Claude Code, Gemini CLI, Cursor, OpenCode, Copilot CLI and other MCP clients on macOS and Linux.

1

Install the local bridge

Registers the helper Chrome uses to reach your agents.

2

Add the extension

Load it in Chrome. It opens the background tabs and tab groups.

3

Add the MCP server

Your agent gets tab, page and input tools.

Terminal
$ npx @csltd/agent-computer-use install
Registered the native host for Google Chrome

$ claude mcp add -s user agent-computer-use \
    -- npx -y @csltd/agent-computer-use mcp
Added stdio MCP server agent-computer-use

$ npx @csltd/agent-computer-use doctor

ok   host launcher at ~/.agent-computer-use/native-host.sh
ok   extension 0.1.0 answered through ~/.agent-computer-use/broker.sock
